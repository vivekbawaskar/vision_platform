Real-Time Object Detection & Logging Platform

Live YOLOv8 detection from webcam, RTSP or video files, with every event persisted to a database and visualised on a Streamlit dashboard.

Live demo Source on GitHub Watch the demo video

YOLOv8 inference

Lazy streaming inference, confidence slider, class filter and optional ByteTrack tracking.

Non-blocking logging

Per-class throttling plus a background batch writer keep SQL off the video loop.

MySQL or SQLite

Parameterised queries, connection pooling and an automatic SQLite fallback.

Self-healing video

Threaded capture serves the latest frame and reconnects when a camera drops.
